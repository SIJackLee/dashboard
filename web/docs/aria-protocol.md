## 생육 권장 온·습도

뱃지 **판정**과 차트 오른쪽 온·습 상·하한의 정본은 **축사유형 권장표**다. LIVE **축사유형**만으로 띠를 고른다. 측정된 일령·체중·방 내부 구역은 판정에 쓰지 않는다.

| 축사유형 | 행 | 온도 | 습도 |
|----------|----|------|------|
| 후보돈사 · 임신사 | 임신돈 | 16~21℃ | 50~60% |
| 분만사 | 분만·포유모돈 | 18~21℃ | 50~60% |
| 베이비하우스 | 이유자돈 | 25~28℃ | 60~80% |
| 자돈사 | 자돈·육성 초기 | 18~22℃ | 50~80% |
| 육성사 · 비육사 · 검정사 | 육성·비육돈 | 15~20℃ | 40~60% |
| 종부사 | 종모돈 | 16~21℃ | 50~60% |

- **분만사** 판정·차트 띠는 모돈 구역만. 자돈 보온 30~35℃는 동 공기 판정에 넣지 않는다.
- 추천 목표: 띠 **안이면 현재값**, 밖이면 **가장 가까운 가장자리** (임신사 24℃ → 21℃).
- 장비 경보 목록 임계(예: 온도 10~35℃)는 **안전망으로 유지**. 뱃지 판정·차트 띠는 표를 쓴다.
- 차트 오른쪽 온·습 상·하한은 **축사유형 권장 띠**다. 알람 저장값과 섞지 않으며, 차트에서 권장 숫자를 고쳐 저장하지 않는다. 왼쪽 온·습 숫자는 현장 알람 **기준**이며, 구간은 투명한 정상색 띠(기준±편차)만 그린다. 겹쳐보기에서는 왼쪽 기준을 세로로 쌓고, 온·습 범위 띠는 각자 색·투명도로 겹친다. 겹친 구간은 조금 더 진하다. 기준 숫자는 클릭·더블클릭·우클릭으로 고친다. 편차는 필드 알람 설정에서 고친다. 같은 값이다.
- 유형 안내 뒤에 「일령별 권장 온·습도도 알려드릴까요?」를 묻고, **네**면 해당 유형의 성장단계 표를 이어서 안내한다. **아니요**면 「축사유형 권장만 안내했습니다.」 통신두절·측정정체·장비경보에서는 묻지 않는다. 적용·명령은 없다.

| 축사유형 | 연계 안내 |
|----------|-----------|
| 후보돈사 · 임신사 | 임신돈 16~21℃ · 50~60% |
| 분만사 | 모돈 실온, 출생 직후, 1주일령, 1주일~이유 전 |
| 베이비하우스 | 이유 시, 이유~45kg |
| 자돈사 | 이유~45kg |
| 육성사 · 비육사 · 검정사 | 45kg~성돈 15~20℃ · 40~60% |
| 종부사 | 종모돈 16~21℃ · 50~60% |

## 허브 뱃지 (단독 인터페이스)

필드·차트 **콘텐츠 영역** 우측 하단(하단 탭 독 위). 차트에서는 브러시 위로 띄움. 기본은 아이콘만, 안내가 있으면 숫자, 누르면 말풍선(이름 DELIN, 제목 + 축사유형별 짧은 목록 최대 3줄, 나머지는 외 N건). 전용 탭 없음. 목록·모델 탭에는 없음. 음성·적용 없음.

**조언 우선순위:** 통신두절 → 측정 정체(수신은 되나 측정 시각이 현재 기준 최신 아님) → 장비 경보(안전망 임계) → 권장표 이탈 → 적정. 통신두절·장비경보는 danger 톤, 측정 정체·권장표 이탈은 warn 톤.

설정 저장·명령 전송·「적용했습니다」 안내는 하지 않는다.
