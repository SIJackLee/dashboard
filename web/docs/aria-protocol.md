## Feature flag

`NEXT_PUBLIC_DELIN_ENABLED` — 뱃지 게이트. 기본: 로컬·Preview on, Production off. `true|false|1|0|on|off` 로 강제.

## 생육 권장 온·습도

뱃지 조언의 정본은 **축사유형 권장표**다. LIVE **축사유형**만으로 띠를 고른다. 일령·체중·방 내부 구역은 쓰지 않는다.

| 축사유형 | 행 | 온도 | 습도 |
|----------|----|------|------|
| 후보돈사 · 임신사 | 임신돈 | 16~21℃ | 50~60% |
| 분만사 | 분만·포유모돈 | 18~21℃ | 50~60% |
| 베이비하우스 | 이유자돈 | 25~28℃ | 60~80% |
| 자돈사 | 자돈·육성 초기 | 18~22℃ | 50~80% |
| 육성사 · 비육사 · 검정사 | 육성·비육돈 | 15~20℃ | 40~60% |
| 종부사 | 종모돈 | 16~21℃ | 50~60% |

- **분만사**는 모돈 구역만. 자돈 보온 30~35℃는 동 공기 판정에 넣지 않는다.
- 추천 목표: 띠 **안이면 현재값**, 밖이면 **가장 가까운 가장자리** (임신사 24℃ → 21℃).
- 장비 경보 목록 임계(예: 온도 10~35℃)는 **안전망으로 유지**. 뱃지만 표를 쓴다.

## 허브 뱃지 (단독 인터페이스)

필드·차트 **콘텐츠 영역** 우측 하단(하단 탭 독 위). 차트에서는 브러시 위로 띄움. 기본은 아이콘만, 안내가 있으면 숫자, 누르면 말풍선(이름 DELIN, 제목 + 축사유형별 짧은 목록 최대 3줄, 나머지는 외 N건). 전용 탭 없음. 목록·모델 탭에는 없음. 음성·적용 없음.

**조언 우선순위:** 통신두절 → 측정 정체(수신은 되나 측정 시각이 현재 기준 최신 아님) → 장비 경보(안전망 임계) → 권장표 이탈 → 적정. 통신두절·장비경보는 danger 톤, 측정 정체·권장표 이탈은 warn 톤.

설정 저장·명령 전송·「적용했습니다」 안내는 하지 않는다.
