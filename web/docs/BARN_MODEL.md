# 축사 3D 모델 (P0 · 테스트)

농장 허브 **모델** 탭. 복도형 박스 매스를 WebGL로 본다. 지붕은 벽과 맞닿게(박공 채움). 방·복도 사이 벽. 지붕 카드는 현장과 같은 축사 아이콘·온·습도, 우측 상단 **X**로 삭제. 필드에서는 지붕에 붙이지 않고 **화면상 동 상자 위**에 뷰 정렬한다. 입구 구도에서는 카드가 입구 상단에 화면 정렬되고, 오른쪽 화면에 차트 탭과 같은 유형 그래프(내용 높이에 맞춰 세로 중앙), 카드 격자 아이콘으로 필드 복귀. 우클릭은 쓰지 않는다. **편집** 버튼으로 전체 필드 카메라로 이동한 뒤 모든 동의 위치·크기·회전을 다룬다. 편집 끝 또는 Esc. 현장·차트 탭으로 나가지 않는다.

구현: `src/lib/farm/barn-model-*.ts`, `src/components/farm/farm-barn-model-*.tsx`  
씬: `farm-barn-model-scene.tsx`(동·마당) · `camera` · `controller-mesh` · `gizmos` · `field-hud` · `types` · `pointer`  
모드: `barn-model-mode.ts` (필드·배치·편집·입구). HUD 클래스: `barn-model-hud.ts`  
URL 계약: [`farm-hub-url.md`](./farm-hub-url.md)

## P0 범위

- 탭: **현장 · 차트 · 모델 · DELIN** (`view=model`)
- **빈 필드**에서 시작. LIVE 축사를 자동으로 세우지 않음
- 사용자: 왼쪽 **이 농장 축사**(LIVE 유형+번호, 평면도 미리보기·컨트롤러 대수, 접기/펼치기) → 반투명 미리보기가 마우스를 따라감 → 클릭 배치. 이미 놓은 동은 눌러 입구로 이동
- 이동은 축사 **뒤·왼쪽 모서리**가 격자에 붙음. **배치·편집 옮기기** 모두 1m 상세 격자. 회전은 **15°**
- 선택 동: 파란 고리로 **회전**. **편집** 시 카메라는 전체 필드(작업 범위 100m, 빈 칸 포함)가 보이게 이동하고, 모든 동에 회전 고리와 치수선이 나온다. 편집 끝 또는 Esc. 바닥 클릭으로 끝나지 않음. 각 동 아래 **방 편집**으로 방 평면(방 하나·복도)을 펼친다. 열면 **그 동으로 줌인**(동·방 편집 카드가 보이게, 도착 높이와 줌 한도를 맞춰 튕기지 않음), 접으면 필드로 돌아온다. **되돌리기**는 방 편집을 연 직후 값으로 복구. 가로·세로·열당 갯수·복도 너비를 넣는다. 열식은 1~3열 버튼. 기본은 유형 표준안. **길이·폭은 이 값으로 계산**되고 치수선은 읽기만 한다. 높이만 치수 숫자를 눌러 바꾼다. 길이는 입구를 고정하고 뒤로 늘어난다. 카메라는 보는 쪽으로 선을 옮긴다. 편집 중에는 입구 줌인 표시를 숨긴다. **편집 중 지붕·박공은 숨기고 외벽은 반투명**이라 칸이 보인다. 크기 입력 중 카메라는 그 동으로 따라가지 않는다.
- **컨트롤러는 축사 유형 LIVE**를 동 전체에 적용. 방마다 꽂지 않음. 지붕은 편집 중이 아니면 불투명. 필드 정보 카드는 지붕이 아니라 **화면상 동 상자 위**에 뷰 정렬. 유형명·축사 아이콘 번호는 현장 개별 카드와 동일 크기, 온·습도·면색은 전체보기와 동일. 좌측 상단 **통합 추이** 버튼, ‹ ›로 다른 동으로 카메라 이동, 우측 상단 **X** 버튼으로 삭제. 입구 쪽 문 아이콘으로 입구 구도. 통합 추이는 필드에서 유형 차트. **편집**으로 모델링. 현장·차트 탭으로 이동하지 않음
- 첫 필드 카메라는 **수직에 가까운 위에서 내려다보기**. 높이와 짙은 격자는 **놓은 동 묶음**에 맞춤(160m 고정 격자 아님). **편집·배치** 중에만 1m 보조 격자가 나온다. 입구 보기만 눈높이. 입구 카메라는 동 폭에 따라 거리를 조절. 정보 카드는 하단이 입구 상단과 맞닿게. 컨트롤러 면은 좌상단 검정 네임플레이트에 번호(`01`, 「번」 없음), 하단 3칸에 채널 `A 27` / `B —` / `C —`. `‹` `›`로 놓은 동 순환, 유형명 탭은 같은 유형, 창고 번호는 컨트롤러 01부터. 유형 LIVE 컨트롤러는 입구 **왼쪽 벽**에 2열 묶음으로 **벽면 중앙**(왼쪽 위=01, 필드 뷰에서는 숨김). 상자 약 0.96×0.74m, 상자 사이 최소 간격 0.24m(가로·세로, 벽에 맞춰 줄이지 않음). 키패드·LED·막대는 생략하고 번호·7세그·채널 3칸만. 목록·카드 표기는 기존처럼 `01번`. 입구 **오른쪽 화면**에는 카메라 이동이 끝난 뒤에 차트 탭과 같은 통합 추이(`FarmChartView`, 내용 높이·세로 중앙). 기본 집계는 그 동의 **축사 유형**(임신사/분만사/자돈사…). 집계 트리는 농장 전체 없이 **유형 → 축사번호 → 컨트롤러**만. 드래그 스코프·기간·설정값 변경은 차트 탭과 동일(명령 권한 있을 때). 왼쪽 상자 클릭은 해당 컨트롤러 집계. 집계에서 컨트롤러를 골라도 왼쪽 상자는 그대로 두고, 고른 상자만 브랜드 색 테두리 glow(점광원 없음). 박공으로 지붕-벽 틈을 막음. 방·복도 사이 칸막이 없음
- HUD는 왼쪽 팔레트(**기본 접힘**, 펼치기 가능). **입구 줌인 시 자동으로 접힘**. 편집 중 각 동 아래 **방 편집**에서 방·복도·칸 수를 입력
- 복도형 박스. 유형별 칸 실측(m):

| 유형 | 칸(복도방향×깊이) | 양쪽+복도 1.8m일 때 동 폭 |
|------|-------------------|---------------------------|
| 임신사 스톨 | 0.65 × 2.2 | 6.2 |
| 분만사 | 1.8 × 2.4 | 6.6 |
| 자돈사 | 2.4 × 5.0 | 11.8 |
| 육성사 | 3.0 × 5.1 | 12.0 |
| 비육사 | 3.6 × 6.5 | 14.8 |

  벽 높이 3.2m(치수선에서 변경 가능). 길이는 칸 수 × 방의 복도 방향 치수 + 끝 여유, 폭은 열 수 × 방 깊이 + 복도 수 × 복도 너비(기본 1.8m, 카드에서 변경). **동 길이 상한 120m**. 복도식 1열=방+복도, 2열=방+복도+방, 3열=방+복도+방+복도+방. 한쪽만 있으면 복도는 빈 쪽으로.
- 배치·각도는 로컬 `localStorage` (농장 키, v2)
- 필드 구도에서 팬/줌. 축사 입구 GUI로 「입구 보기」
- 패키지: `three`, `@react-three/fiber`, `@react-three/drei`

넣지 않음: 돼지·급이선·분뇨피트·실측 CAD·제품 메시·Production 노출·서버 저장.
