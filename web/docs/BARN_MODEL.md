# 축사 3D 모델 (P0 · 테스트)

농장 허브 **모델** 탭. 복도형 박스 매스를 WebGL로 본다. 지붕은 벽과 맞닿게(박공 채움). 방·복도 사이 벽. 지붕 카드는 현장과 같은 축사 아이콘·온·습도, 우측 상단 **X**로 삭제. 입구 구도에서는 카드가 입구 **상단 벽면**, 오른쪽 화면에 차트 탭과 같은 유형 그래프(내용 높이에 맞춰 세로 중앙), 하단 격자 아이콘으로 필드 복귀. 우클릭은 모델링 편집(그 동 중심으로 카메라 이동). 현장·차트 탭으로 나가지 않는다.

구현: `src/lib/farm/barn-model-*.ts`, `src/components/farm/farm-barn-model-*.tsx`  
URL 계약: [`farm-hub-url.md`](./farm-hub-url.md)

## P0 범위

- 탭: **현장 · 차트 · 모델 · DELIN** (`view=model`)
- **빈 필드**에서 시작. LIVE 축사를 자동으로 세우지 않음
- 사용자: 왼쪽 **이 농장 축사**(LIVE 유형+번호, 평면도 미리보기·컨트롤러 대수, 접기/펼치기) → 반투명 미리보기가 마우스를 따라감 → 클릭 배치. 이미 놓은 동은 눌러 입구로 이동
- 이동은 축사 **뒤·왼쪽 모서리**가 **5m** 격자에 붙음(1m 보조 격자). 회전은 **15°**
- 선택 동: 파란 고리(회전) · **길이** 화살표(입구 하단 1개) / 좌·우 방 막대 핸들(글자 카드 없음). 우클릭 편집 시 그 동이 화면 가운데로 오고, 다시 우클릭하거나 Esc로 끝낸다(바닥 클릭·핸들 조작으로 끝나지 않음). 편집 중 동 세 변에 **치수선**(가로=가까운 짧은 변, 세로=가까운 긴 변, 높이=가까운 모서리)과 선 가운데 숫자만 보여 준다. 카메라는 보는 쪽으로 선을 옮긴다. 편집 중에는 입구 줌인 표시를 숨긴다. 핸들을 뒤로 끌면 그 쪽 방이 늘고, 입구 쪽으로 끌면 줄어든다. 입구는 고정되고 방은 뒤쪽으로만 늘어난다. **편집 중 지붕·박공은 숨기고 외벽은 반투명**이라 좌·우 방 핸들과 칸이 보인다. 편집 카메라 거리·줌은 세션 동안 고정이다.
- **컨트롤러는 축사 유형 LIVE**를 동 전체에 적용. 방마다 꽂지 않음. 지붕은 편집 중이 아니면 불투명. 지붕 카드: 유형명·축사 아이콘 번호는 현장 개별 카드와 동일 크기, 온·습도·면색은 전체보기와 동일. 좌측 상단 그래프 아이콘으로 이력, 우측 상단 **X**로 삭제. 입구 쪽 문 아이콘으로 입구 구도. 우클릭은 모델링 편집. 현장·차트 탭으로 이동하지 않음
- 첫 필드 카메라는 **수직에 가까운 위에서 내려다보기**. 높이와 격자는 **놓은 동 묶음**에 맞춤(160m 고정 격자 아님). 입구 보기만 눈높이. 입구 카메라는 동 폭에 따라 거리를 조절. 정보 카드는 입구 **상단 벽면**(그래프 아이콘 없음). `‹` `›`로 놓은 동 순환, 유형명 탭은 같은 유형, 창고 번호는 컨트롤러 01부터. 유형 LIVE 컨트롤러는 입구 **왼쪽 벽**에 2열 묶음으로 **벽면 중앙**(왼쪽 위=01, 필드 뷰에서는 숨김). 상자 **하단 좌측**에 채널 `A-출력 B-출력 C-출력`을 가로로. 입구 **오른쪽 화면**에는 차트 탭과 같은 통합 추이(`FarmChartView`, 내용 높이·세로 중앙). 기본 집계는 그 동의 **축사 유형**(임신사/분만사/자돈사…). 집계 트리는 농장 전체 없이 **유형 → 축사번호 → 컨트롤러**만. 드래그 스코프·기간·설정값 변경은 차트 탭과 동일(명령 권한 있을 때). 왼쪽 상자 클릭은 해당 컨트롤러 집계. 집계에서 컨트롤러를 골라도 왼쪽 상자는 그대로 두고, 고른 상자만 glow. 박공으로 지붕-벽 틈을 막음. 방·복도 사이 칸막이 없음
- HUD는 왼쪽 팔레트(접기 가능). **입구 줌인 시 자동으로 접힘**. 하단 폼·커스텀 추가 없음
- 복도형 박스. 유형별 칸 실측(m):

| 유형 | 칸(복도방향×깊이) | 양쪽+복도 1.8m일 때 동 폭 |
|------|-------------------|---------------------------|
| 임신사 스톨 | 0.65 × 2.2 | 6.2 |
| 분만사 | 1.8 × 2.4 | 6.6 |
| 자돈사 | 2.4 × 5.0 | 11.8 |
| 육성사 | 3.0 × 5.1 | 12.0 |
| 비육사 | 3.6 × 6.5 | 14.8 |

  벽 높이 3.2m. 길이는 칸 수 × 칸 폭 + 끝 여유. 한쪽만 있으면 복도는 빈 쪽으로.
- 배치·각도는 로컬 `localStorage` (농장 키, v2)
- 필드 구도에서 팬/줌. 축사 입구 GUI로 「입구 보기」
- 패키지: `three`, `@react-three/fiber`, `@react-three/drei`

넣지 않음: 돼지·급이선·분뇨피트·실측 CAD·제품 메시·Production 노출·서버 저장.
