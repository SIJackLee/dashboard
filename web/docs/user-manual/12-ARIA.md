# 12. DELIN — 권장 안내

필드·차트 **우측 하단 뱃지**가 지금 보는 축사유형의 권장 온·습도를 말풍선으로 알려 줍니다. 모델 탭(평면 생성)에서는 숨깁니다. 상단 **전용 탭은 없습니다.**

**DELIN** = *Data-driven Environmental & Livestock Intelligence Navigator*  
**델린** = 데이터 기반 축사 환경·가축 지능형 안내자  

이름은 목동과 가축의 수호성인 성 벤델리노(Wendelin)에서 유래했습니다.  
**축사를 이해하고, 농장을 지키는 AI — DELIN**

권장 정본은 **축사유형 온·습 띠**입니다. 수치는 LIVE 지금값과 표를 대조합니다. 설정은 바꾸지 않습니다.

## 개요

![델린 보기](./images/12-farm-aria.png)

> 스크린샷이 없으면 `/farm` 필드·차트·모델에서 우측 하단 뱃지를 캡처해 `images/12-farm-aria.png`로 저장하세요.

### 이 화면에서 할 수 있는 것

- **우측 하단 뱃지**: 필드·차트에서 동일합니다. 목록·모델에는 없습니다. 기본은 아이콘만, 안내가 있으면 숫자, 누르면 말풍선.
- **말풍선**: 이름 DELIN, 제목(벗어남/적정), 축사유형별 짧은 목록(최대 3줄, 나머지는 외 N건).
- **맥락**: 필드에서 고른 동, 차트 집계 유형, 모델에서 고른 구역 유형.

### 할 수 없는 것 (중요)

- 컨트롤러 **설정 적용·명령 전송**을 델린이 대신하지 않습니다.
- 「적용했습니다」류 안내는 **하지 않습니다**.
- 실제 설정 변경은 **목록·그리드 일괄적용**에서 직접 합니다. → [03-일괄적용.md](./03-일괄적용.md) · [04-컨트롤러-설정.md](./04-컨트롤러-설정.md)

## 사용 순서

1. 헤더에서 확인할 **농장**을 고릅니다.
2. **필드 / 차트 / 모델**을 엽니다.
3. 우측 하단 아이콘(안내가 있으면 숫자)을 눌러 말풍선을 확인합니다.
4. 설정 변경이 필요하면 **목록·그리드**에서 직접 적용합니다.
