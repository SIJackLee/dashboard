# 11. 모니터링 — 차트

농장 전체·축사유형·축사·컨트롤러 단위로 **추이 그래프**를 보는 보기입니다. 상단에서 **차트** 탭을 선택합니다.

그리드·목록과 **기간(24시간 → 7일 → 30일 순환)** 을 공유합니다. 기간만 바꿔도 차트 탭에 그대로 머무릅니다.

그래프의 시간축은 **센서 측정 시각**입니다. 통신이 끊겼다가 다시 연결되면 컨트롤러에 쌓인 과거 측정값이 짧은 간격으로 올라오더라도, 차트에는 측정했던 시각(보통 5분 간격)에 맞춰 채워집니다. 화면 카드의 “지금 연결됐는지”는 이와 별도로 **수신 시각**을 봅니다.

### 이 화면에서 할 수 있는 것

- **큰 통합 추이**: 선택한 집계 범위의 온도·습도·팬 추이를 한 그래프에서 봅니다.
- **집계 범위 (우측 트리)**: 농장 전체 → 축사유형 → 축사 → 컨트롤러 순으로 좁힙니다. PC에서는 패널 우측 아이콘으로 **숨기기/나타내기**할 수 있고, 숨기면 차트 영역이 넓어집니다.
- **기간**: 헤더·도구의 24시간 / 7일 / 30일과 동기화됩니다. → [01-모니터링-그리드.md](./01-모니터링-그리드.md)
- **레이어(표시 항목)**: 기본은 **온도·습도·모터 본선**만 켭니다. 아이콘을 누르면 본선 → 전체(범위·분포·추세) → 끔 순으로 바뀝니다. **지표를 하나만** 켜면 Y축이 ℃/% 원단위로 바뀝니다. 모터는 **채널 A/B/C**, 추세·범위·분포는 **온도 추세**·**온도 범위**·**온도 분포**처럼 표시됩니다. 본선만 켠 상태(또는 모바일)에서는 범례가 핵심 항목만 보여 주고, 상세 레이어를 켜면 PC에서 전체 범례가 펼쳐집니다. **차트 탭**에서만 글자·버튼·플롯 높이에 **2배** 스케일이 적용됩니다(현장 목록 카드 그래프는 1×).
- **알람 상·하한**: 우측 **숫자 라벨을 세로 드래그**하거나 **우클릭**해 알람 임계값을 조절합니다. 차트 본문 드래그는 기존처럼 **시간 구간 줌**입니다. 저장은 현재 **집계 범위**와 같은 계층에 반영됩니다. 뷰어는 조회만 가능합니다.
- **설정모드**: **설정모드** 버튼으로 들어가면 시간 줌·알람 편집이 잠시 멈추고, **보라색 설정온도(굵은 실선 = 최저환기)** 와 **설정+온도편차(얇은 선 = 최고환기)** 를 드래그해 맞춘 뒤 설정온도 옆 **체크(✓)** 로 **LIVE 명령을 전송**합니다(집계 범위 온라인 컨트롤러). 되돌리기(↻)는 초안만 취소합니다. 편차는 설정온도 **위쪽만** 있습니다. 환기 % 직접 조절은 이후 추가 예정입니다.

### 그리드·목록과의 차이

| 보기 | 초점 |
|------|------|
| 그리드 | 배치·히트맵·이상 위치 |
| 목록 | 컨트롤러 카드·설정·일괄적용 |
| 차트 | 범위별 **시계열** 비교 |

일괄적용·설정 적용은 차트 탭이 아니라 **목록**·그리드 일괄에서 합니다. → [02-모니터링-목록.md](./02-모니터링-목록.md) · [03-일괄적용.md](./03-일괄적용.md)

## 집계 범위 바꾸기

1. 차트 탭에서 우측(또는 모바일에서는 범위 선택 UI) **트리**를 엽니다.
2. 축사유형 → 축사 → 컨트롤러를 골라 범위를 좁힙니다.
3. 선택한 범위의 추이가 큰 그래프에 반영됩니다.
4. **로고(모니터링 홈)** 또는 **그리드**로 나가면 차트 집계 선택은 초기화됩니다. 농장·기간은 유지됩니다.

> **뷰어**: 차트 조회만 가능합니다. 명령·설정 적용은 없습니다. → [09-역할별-차이.md](./09-역할별-차이.md)

개발용 URL(`view=chart`, 집계 쿼리)은 [`../farm-hub-url.md`](../farm-hub-url.md)를 보세요.
