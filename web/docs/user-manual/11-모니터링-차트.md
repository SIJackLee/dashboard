# 11. 모니터링 — 차트

농장 전체·축사유형·축사·컨트롤러 단위로 **추이 그래프**를 보는 보기입니다. 상단에서 **차트** 탭을 선택합니다.

그리드·목록과 **기간(24시간 / 7일 / 30일)** 을 공유합니다. 기간만 바꿔도 차트 탭에 그대로 머무릅니다.

## 차트 개요

![차트 보기](./images/11-farm-chart.png)

> 스크린샷이 아직 없으면 `/farm` → **차트** 탭을 캡처해 `images/11-farm-chart.png`로 저장하세요.

### 이 화면에서 할 수 있는 것

- **큰 통합 추이**: 선택한 집계 범위의 온도·습도·팬 추이를 한 그래프에서 봅니다.
- **집계 범위 (우측 트리)**: 농장 전체 → 축사유형 → 축사 → 컨트롤러 순으로 좁힙니다.
- **기간**: 헤더·도구의 24시간 / 7일 / 30일과 동기화됩니다. → [01-모니터링-그리드.md](./01-모니터링-그리드.md)
- **레이어(표시 항목)**: 온도·습도·모터(팬) 등 표시를 켜고 끌 수 있습니다(PC).
- **알람 상·하한**: 우측 **숫자 라벨을 세로 드래그**하거나 **우클릭**해 알람 임계값을 조절합니다. 차트 본문 드래그는 기존처럼 **시간 구간 줌**입니다. 저장은 현재 **집계 범위**와 같은 계층에 반영됩니다. 뷰어는 조회만 가능합니다.

### 그리드·목록과의 차이

| 보기 | 초점 |
|------|------|
| 그리드 | 배치·히트맵·이상 위치 |
| 목록 | 컨트롤러 카드·설정·일괄적용 |
| 차트 | 범위별 **시계열** 비교 |

일괄적용·설정 적용은 차트 탭이 아니라 **목록**·그리드 일괄에서 합니다. → [02-모니터링-목록.md](./02-모니터링-목록.md) · [03-일괄적용.md](./03-일괄적용.md)

## 집계 범위 바꾸기

1. 차트 탭에서 우측(또는 모바일에서는 범위 선택 UI) **트리**를 엽니다.
2. 축사유형 → 축사 → 컨트롤러를 골라 범위를 좁힙니다.
3. 선택한 범위의 추이가 큰 그래프에 반영됩니다.
4. **로고(모니터링 홈)** 또는 **그리드**로 나가면 차트 집계 선택은 초기화됩니다. 농장·기간은 유지됩니다.

> **뷰어**: 차트 조회만 가능합니다. 명령·설정 적용은 없습니다. → [09-역할별-차이.md](./09-역할별-차이.md)

개발용 URL(`view=chart`, 집계 쿼리)은 [`../farm-hub-url.md`](../farm-hub-url.md)를 보세요.
