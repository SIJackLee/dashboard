# 11. 모니터링 — 차트

농장 전체·축사유형·축사·컨트롤러 단위로 **추이 그래프**를 보는 보기입니다. 상단에서 **차트** 탭을 선택합니다.

그리드·목록과 **기간(24시간 → 7일 → 30일 순환)** 을 공유합니다. 기간만 바꿔도 차트 탭에 그대로 머무릅니다.

그래프의 시간축은 **센서 측정 시각**입니다. 통신이 끊겼다가 다시 연결되면 컨트롤러에 쌓인 과거 측정값이 짧은 간격으로 올라오더라도, 차트에는 측정했던 시각(보통 5분 간격)에 맞춰 채워집니다. 화면 카드의 “지금 연결됐는지”는 이와 별도로 **수신 시각**을 봅니다.

측정값이 비어 있는 구간은 차트에 **색면·구간 라벨을 그리지 않습니다.** 선만 이렇게 그립니다.

| 구분 | 의미 | 선 |
|------|------|-----|
| 값이 거의 같아 이력을 줄인 구간 | 컨트롤러는 계속 보내고 있음 | 직전 값을 **유지** |
| 그 시간에 수신이 없음 | 통신이 끊김 | 선을 **끊음** |
| 수신은 있으나 쓸 수 없는 값 | 잘못된 축사유형, 옛 형식 폐기 등 | 선을 끊고 값을 만들지 않음 |

습도처럼 한 번도 측정되지 않은 항목은 값을 채우지 않습니다.

### 이 화면에서 할 수 있는 것

- **큰 통합 추이**: 선택한 집계 범위의 온도·습도·팬 추이를 한 그래프에서 봅니다. 점을 **클릭**하면 데이터 카드가 뜨고, 점과 카드는 **점선**으로 이어집니다. 다시 클릭하거나 카드의 닫기로 뺍니다. 날짜·시각 글자와 격자 눈금은 그래프 아래 **회색 시간축**에 둡니다. 구간 끝 날짜를 억지로 붙이지 않습니다. 점의 가로 위치도 **같은 달력 시간**입니다. 기준선 **아래**에 날짜·시간을 두 줄로 잡고, 같은 날은 날짜를 반복하지 않습니다. 자정이 걸려도 축 높이는 같습니다. 정각은 `12`처럼 분을 생략합니다. 정확한 시각은 호버 카드와 브러시 칩에 있습니다. 추이를 불러오는 동안에는 빈 그래프 대신 불러오는 중 안내가 나옵니다.
- **집계 범위 (우측 트리)**: 농장 전체 → 축사유형 → 축사 → 컨트롤러 순으로 좁힙니다. PC에서는 패널 우측 아이콘으로 **숨기기/나타내기**할 수 있고, 숨기면 차트 영역이 넓어집니다.
- **기간**: 그리드·목록의 24시간 / 7일 / 30일은 그대로입니다. 차트 하단 브러시는 **30일 안에서 구간을 직접** 고르며, 이 선택은 다른 탭 기간을 바꾸지 않습니다. → [01-모니터링-그리드.md](./01-모니터링-그리드.md)
- **레이어(표시 항목)**: 기본은 **온도·습도 본선+산포**, **모터 본선**입니다. 측정값이 없어도 **습도·모터 구간**은 열어 두고, 습도 상·하한과 최저·최고 환기 안내선을 둡니다. 아이콘을 누르면 **기본보기 ↔ 끔**만 바뀝니다(상세보기·범위·추세·편차 일괄 단계는 없습니다). **지표를 하나만** 켜면 Y축이 ℃/% 원단위로 바뀝니다. 모터는 **채널 A/B/C**, 산포는 **온도 산포**·**습도 산포**(시점별 최솟값~최댓값)처럼 표시됩니다. **알람·설정온도·환기 가이드 드래그**는 **설정모드**에서만 가능합니다. **차트 탭**에서만 글자·버튼·플롯 높이에 **2배** 스케일이 적용됩니다(현장 목록 카드 그래프는 1×). 현장 라인도 차트와 같이 플롯 너비에 맞춰 점을 줄이지만, **상시 점 마커와 구간 줌은 없습니다**(핀·카드는 있습니다).
- **알람 상·하한**: 설정모드에서 우측 **숫자 라벨을 세로 드래그**하거나 **더블클릭(PC)·더블탭(모바일)·우클릭**으로 값을 직접 입력합니다. 입력 시 명칭·단위는 그대로 두고 숫자만 바꿉니다. 차트 본문 드래그는 기존처럼 **시간 구간 줌**입니다. 저장은 현재 **집계 범위**와 같은 계층에 반영됩니다. 뷰어는 조회만 가능합니다.
- **설정모드**: **설정모드** 버튼으로 들어가면 시간 줌이 잠시 멈추고, **온·습 알람 상·하한**과 **보라색 설정온도·온도편차·환기%** 를 드래그하거나 더블클릭/더블탭으로 맞춘 뒤, 설정모드 버튼 아래 **체크(✓)** 로 **명령을 전송**합니다. 적용한 값이 바로 표시되며, 연결된 컨트롤러에는 곧 반영됩니다. 편차는 설정온도 **위쪽만** 있습니다.
- **하단 구간 바**: 30일 양호도를 보여 줍니다. **드래그**하면 그 구간이 차트에 열리고, **탭**하면 지금 폭을 유지한 채 위치를 옮기며, **우클릭**하면 30일 전체로 돌아갑니다. 트랙의 옅은 점선은 양호도 75점 기준입니다. 숫자는 호버 카드에서만 봅니다.

> 헤더 **물음표(기능 안내)** 로 차트 탭에서 위 흐름을 순서대로 다시 볼 수 있습니다.

### 그리드·목록과의 차이

| 보기 | 초점 |
|------|------|
| 그리드 | 배치·히트맵·이상 위치 |
| 목록 | 컨트롤러 카드·설정·일괄적용 |
| 차트 | 범위별 **시계열** 비교 |

일괄적용·설정 적용은 차트 탭이 아니라 **목록**·그리드 일괄에서 합니다. → [02-모니터링-목록.md](./02-모니터링-목록.md) · [03-일괄적용.md](./03-일괄적용.md)

## 집계 범위 바꾸기

1. 차트 탭에서 우측(또는 모바일에서는 범위 선택 UI) **트리**를 엽니다.
2. 축사유형 → 축사 → 컨트롤러를 골라 범위를 좁힙니다.
3. 선택한 범위의 추이가 큰 그래프에 반영됩니다.
4. **로고(모니터링 홈)** 또는 **그리드**로 나가면 차트 집계 선택은 초기화됩니다. 농장·기간은 유지됩니다.

> **뷰어**: 차트 조회만 가능합니다. 명령·설정 적용은 없습니다. → [09-역할별-차이.md](./09-역할별-차이.md)

개발용 URL(`view=chart`, 집계 쿼리)은 [`../farm-hub-url.md`](../farm-hub-url.md)를 보세요.
