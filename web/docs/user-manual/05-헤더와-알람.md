# 5. 헤더와 알람

오른쪽 상단 **도구(⋮)** 메뉴와 **계정**으로 알림·기능·스타일을 다룹니다.

## 헤더 도구 메뉴

도구 아이콘을 누르면 **알림 → 기능 → 스타일** 순으로 세로로 펼쳐집니다. 알림·오프라인이 있으면 배지가 표시됩니다.

### 알림

- **컨트롤러 연결**: 등록·연결·오프라인 대수 요약(컨트롤러 아이콘).
- **센서 알림**: 활성 건수 배지와 최근 알림 목록. 항목을 누르면 관련 컨트롤러로 이동합니다.
- 전체 목록은 「이상 탭으로 이동」으로 이어집니다.

> 예전 독립 `/alarms` 화면은 없으며, 도구 메뉴와 모니터링에서 통합 확인합니다.

### 기능

- **운영**(관리자): 운영 ↔ 모니터링 전환.
- **오늘의 리포트**: 활성 농장 기준 PDF 다운로드.

### 스타일

- **PC / 모바일 레이아웃**: 미리보기 수동 전환(자동 감지 해제).
- **라이트 / 다크**: 화면 밝기 전환(이 기기에 저장).

## 계정 메뉴

![계정 메뉴](./images/05-header-account.png)

### 이 화면에서 할 수 있는 것

- **이름 · 이메일 · 역할**: 현재 로그인 계정과 관리자/운영자/뷰어를 확인합니다.
- **기능 안내 다시 보기**: 인앱 투어를 처음부터 다시 실행합니다.
- **최근 활동**: 최근 명령·상태 요약(표시되는 경우).
- **농장 주소**: 주소 검색·저장(운영자 등 권한이 있는 경우).
- **로그아웃**: 헤더의 로그아웃 버튼으로도 동일하게 종료합니다.
