# 5. 헤더와 알람

오른쪽 상단 **도구 아이콘**과 **계정**으로 알림·기능·스타일을 다룹니다.

## 헤더 도구

아이콘이 헤더에 **상시** 보입니다. 알림·오프라인이 있으면 이상상황 배지가 표시됩니다.

순서(왼쪽 → 오른쪽, 계정 직전): **이상상황 · 운영(관리자) · 오늘의 리포트 · 라이트/다크 · PC/모바일(넓은 화면)**.

- **이상상황**: **모듈 에러코드** + **통신 두절** 건수 배지. 누르면 목록이 펼쳐집니다. (대시보드가 온·습 임계를 다시 계산해 이상상황으로 올리지 않습니다.)
- **확인**: 모듈 경보 행의 **확인**을 누르면 해당 경보가 활성 목록에서 빠집니다. (통신 두절 행에는 확인이 없습니다. 현장 조치·모듈 재전송 여부와는 별개입니다.)
- **운영**(관리자): 운영 ↔ 모니터링 전환.
- **오늘의 리포트**: 활성 농장 기준 PDF 다운로드. 표지의 이상상황은 **모듈 에러·통신 두절**과 동일하며, 온·습 임계 가이드 이탈은 포함하지 않습니다.
- **라이트 / 다크**: 화면 밝기 전환(이 기기에 저장).
- **PC / 모바일 레이아웃**: 넓은 화면에서만 미리보기 수동 전환(자동 감지 해제). 좁은 화면·실기기에서는 숨깁니다.

> 예전 독립 `/alarms` 화면은 없으며, 헤더 도구와 모니터링에서 통합 확인합니다.  
> 차트·목록에 보이는 온·습 상·하한은 **참조 가이드(임계)** 이며, 이상상황 배지와는 별개입니다.  
> **기기 알림:** 문자·전화가 아니라, 대시보드를 **앱으로 설치**한 뒤 **푸시 알림**으로 받을 예정입니다 (구현 후속).

## 계정 메뉴

![계정 메뉴](./images/05-header-account.png)

### 이 화면에서 할 수 있는 것

- **이름 · 이메일 · 역할**: 현재 로그인 계정과 관리자/운영자/뷰어를 확인합니다.
- **기능 안내**: 헤더 물음표. 농장 모니터링에서 누르면 **현재 탭**(현장·차트·델린) 안내가 다시 실행됩니다.
- **최근 활동**: 최근 명령·상태 요약(표시되는 경우).
- **농장 주소**: 주소 검색·저장(운영자 등 권한이 있는 경우).
- **로그아웃**: 헤더의 로그아웃 버튼으로도 동일하게 종료합니다.
